📝 Formulário de Matrícula (Estrelas do Amanhã)

Uma página web moderna e acessível contendo um formulário completo de matrícula escolar, desenvolvida com foco em semântica HTML, estilização avançada em CSS e excelente experiência do usuário (UX).

🎯 Sobre o Projeto

Este projeto consiste em uma interface de cadastro/matrícula escolar com layout em duas colunas: uma seção lateral de apresentação/boas-vindas com visual estilizado e uma área principal com formulário detalhado e segmentado por etapas.

O objetivo foi trabalhar na prática a estilização e personalização de componentes de formulário nativos da web, garantindo acessibilidade, responsividade e consistência visual.

🌐 Demonstração

🔗 Acesse online: https://form-matricula.vercel.app

🛠️ Tecnologias Utilizadas

HTML5: Estruturação semântica (<fieldset>, <legend>, <input>, <select>, <textarea>).


CSS3: Flexbox, CSS Grid, estilização avançada de pseudo-classes (:focus, :hover, :checked, :has()) e responsividade com Media Queries.


CSS Customization: Estilização personalizada de componentes nativos como radio buttons, checkboxes, custom file upload (dropzone) e seletores de data.


✨ Funcionalidades e Seções


[x] Dados da Criança: Nome completo, data de nascimento, gênero (seleção customizada) e informações médicas/alergias.


[x] Endereço Residencial: CEP, logradouro, número, complemento, bairro e cidade/estado.


[x] Dados do Responsável: Nome, telefone de emergência, e-mail e parentesco.


[x] Opções de Matrícula: Seleção de turno (matutino/vespertino) e atividades extracurriculares.


[x] Upload de Documentos: Campo de anexos em estilo dropzone para envio da certidão de nascimento e carteira de vacinação.


[x] Design Responsivo: Adaptação suave para dispositivos móveis, tablets e telas desktop.

🚀 Como Executar Localmente

Pré-requisitos

Para rodar o projeto, você só precisa de um navegador moderno instalado na sua máquina.

Passo a passo

# 1. Clone o repositório
git clone https://github.com/Golskilamaster09/form-matricula.git

# 2. Acesse a pasta do projeto
cd form-matricula

# 3. Abra o arquivo index.html no navegador
# No Windows:
start index.html

# No Linux:
xdg-open index.html

# No macOS:
open index.html


(Ou utilize a extensão Live Server no VS Code para rodar localmente com recarregamento automático).
