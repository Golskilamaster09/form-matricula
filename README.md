# 📋 Formulário de Matrícula

Interface moderna e responsiva de formulário para matrícula escolar, desenvolvida com foco em semântica HTML, estilização avançada em CSS e excelente experiência do usuário (UX).

---

## 🎯 Sobre o Projeto

Este projeto consiste em uma interface de cadastro/matrícula escolar com layout estruturado: uma seção lateral de apresentação/boas-vindas com visual estilizado e uma área principal com formulário detalhado e segmentado por etapas.

O objetivo foi trabalhar na prática a estilização e personalização de componentes de formulário nativos da web, garantindo acessibilidade, responsividade e consistência visual.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica (`<form>`, `<fieldset>`, `<legend>`, `<input>`, `<select>`, `<textarea>`).
- **CSS3:** Flexbox, CSS Grid, estilização avançada de pseudo-classes (`:focus`, `:hover`, `:checked`, `:has()`) e responsividade com Media Queries.
- **CSS Customization:** Estilização personalizada de componentes nativos como radio buttons, checkboxes, custom file upload (dropzone) e seletores de data.

---

## ✨ Funcionalidades e Seções

- [x] **Dados da Criança:** Nome completo, data de nascimento, gênero e informações médicas/alergias.
- [x] **Endereço Residencial:** CEP, logradouro, número, complemento, bairro e cidade/estado.
- [x] **Dados do Responsável:** Nome, telefone de emergência, e-mail e parentesco.
- [x] **Opções de Matrícula:** Seleção de turno (matutino/vespertino) e atividades extracurriculares.
- [x] **Upload de Documentos:** Campo de anexos em estilo dropzone para envio de certidão e comprovantes.
- [x] **Design Responsivo:** Adaptação suave para dispositivos móveis, tablets e telas desktop.
